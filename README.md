# Mini Store

A small Python application built while learning Python software engineering fundamentals.

## Features

- Customer management
- Product management
- Order management
- Order confirmation
- Payment abstraction
- Wallet payment
- Card payment
- UPI payment
- Service layer
- Python package structure
